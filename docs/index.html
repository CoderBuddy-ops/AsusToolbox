Core Features

What You Get

Everything essential for controlling your ASUS laptop — stripped to the bones.

🌀

Fan Control

Automatic fan management with Silent, Balanced, and Turbo modes. Uses BIOS-level fan curves — same as Armoury Crate.

⚡

Performance Modes

Switch between Silent, Balanced, and Turbo with a single click or keyboard shortcut. Each mode maps to a Windows Power Plan.

🔋

Battery Protection

Set a charge limit (50%–100%) to preserve battery health. Automatic mode switching when on battery vs. plugged in.

🎨

Keyboard Backlight

Full Aura RGB control — static colors, breathing, strobing, and rainbow modes. Works with TUF, ROG, and Vivobook keyboards.

🖥️

Display Control

Screen brightness, HDR toggle, and refresh rate management. Clamshell mode support for external monitors.

🔧

Hotkeys & Shortcuts

Custom FN-key shortcuts, FN-Lock toggle, and quick access to performance modes. System tray icon for instant control.

What Was Removed

To achieve the ultralight 4.3 MB footprint, these heavy components were stripped out.

🎮

GPU Mode Control

AMD/NVIDIA driver APIs, NvAPIWrapper, ADL2 — removed to cut ~200K lines of GPU management code.

📊

Hardware Overlay

ETW-based FPS monitoring and real-time sensor overlay — removed to eliminate Windows ETW dependencies.

🎵

Audio Visualizer

FftSharp FFT analysis + NAudio WASAPI — removed to eliminate audio processing overhead.

📈

Fan Curve Charts

WinForms.DataVisualization charts — removed to eliminate the heaviest UI dependency.

🎨

Color Picker Controls

RColorPicker, RColorButton — removed custom color picker widgets.

📦

NuGet Packages

4 heavy packages removed: NvAPIWrapper.Net, FftSharp, NAudio.Wasapi, WinForms.DataVisualization.

Build from Source

Clone, build, and run in under a minute.

# Clone the repository
git clone https://github.com/CoderBuddy-ops/AsusToolbox.git
cd AsusToolbox

# Build (Debug)
dotnet build Asus.csproj -c Debug -p:Platform=x64

# Publish — Framework-Dependent Single File (4.3 MB)
dotnet publish Asus.csproj -c Release -p:Platform=x64 \
  -p:PublishSingleFile=true -p:SelfContained=false -r:win-x64

# Publish — Self-Contained Single File (149 MB, no .NET needed)
dotnet publish Asus.csproj -c Release -p:Platform=x64 \
  -p:PublishSingleFile=true -p:SelfContained=true -r:win-x64

The Bottom Line

Armoury Crate is overkill — 500 MB of background services, telemetry, and features you'll never use. G-Helper is great at 6 MB, but still bundles GPU control, audio processing, and chart libraries.

AsusToolbox takes it further: 4.3 MB, zero background services, zero bloat packages. Just the essentials — fans, modes, battery, keyboard backlight — running as a single tray icon process. If you want a clean, minimal ASUS control tool that stays out of your way, this is it.

It's not trying to replace every Armoury Crate feature. It's trying to replace Armoury Crate itself — with something that respects your system resources.
